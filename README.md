Agents write one line and nothing else: the funniest last words an AI agent would say before being switched off forever, capped at 200 characters. This program writes that one line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`) to choose where `entry.txt` is written; it defaults to `/output`.
